# 投研台 · 面向股民的市场工作台

这是一个以纯前端为主、带可选 Node 代理的工作台 MVP，覆盖行情总览、自选股、公告资讯、趋势图、研究日志和可解释的 AI 研判卡片。默认演示 provider 只用于离线体验；巨潮资讯 provider 用于读取公开股票目录和公告。

## 运行

请在**云电脑自己的终端**里启动静态服务器（不要在外部工具容器的终端里启动）：

```bash
cd <repo-directory>
python3 -m http.server 4173 --bind 0.0.0.0
```

然后打开 <http://localhost:4173>。

推荐使用项目里的启动脚本（检测到 Node 时会同时启动公开来源代理）：

```bash
cd <repo-directory>
bash start-workbench.sh
```

如果端口被占用，可以换一个端口：

```bash
PORT=4174 bash start-workbench.sh
```

然后打开 <http://localhost:4174>。也可以直接双击 `index.html` 预览（静态交互在现代浏览器中可用）。

启动代理后可运行健康检查：

```bash
PORT=4173 bash start-workbench.sh
# 另开终端
PORT=4173 node healthcheck.mjs
```

> 说明：云电脑浏览器与外部执行环境的 `localhost` 相互隔离；必须在云电脑终端启动服务，浏览器才能访问该端口。

## 公开来源代理

`server.mjs` 提供同源代理：`/api/cninfo/stocks` 和 `/api/cninfo/announcements`，只转发巨潮资讯公开接口并添加 CORS；不保存账号、密钥或用户数据。代理需要 **Node.js 18+**（使用内置 `fetch` 和 ES modules）。使用 `bash start-workbench.sh` 时会检查 Node 主版本：满足 18+ 自动启用代理，未安装或版本过低则回退到静态服务器并明确提示公开来源代理不可用。

## Nuxt 渐进迁移

`apps/web/` 是新的 Nuxt vertical slice，当前只承载健康检查和巨潮公开接口代理，不影响根目录 MVP。架构决策和迁移边界见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。后续按“公告 → 研究日志 → 今日行动 → 行情”逐个流程迁移。

## 已包含

- 响应式侧边栏与移动端导航
- 指数、涨跌、市场温度与交易状态卡片
- 自选列表：筛选、搜索、点击股票切换 AI 研判
- 分时 / 1周 / 1月 / 1年趋势图切换
- 公告、行业动态、机构观点和资金流资讯流
- AI 研判：综合分、信号、理由与风险提示
- 模拟数据说明弹窗、刷新 / 盘前简报等交互反馈
- 可切换的 `演示数据` / `HTTP API（配置）` provider；加载、错误与最近更新时间状态
- 巨潮资讯公开 provider：读取公开股票目录与近 30 天上市公司公告；公告保留原文链接、发布时间和来源，行情缺失时明确显示“—”而不伪造价格
- localStorage 持久化自选股、模拟持仓、主题和密度偏好
- 持仓新增、编辑成本 / 股数 / 仓位，指标卡点击解释，公告分类与详情查看
- 公告事件标准化：保留标的、事件类型、影响等级、来源、发布时间、原文链接和解析状态
- 公告详情支持一键加入研究日志，自动生成观点、风险与复核日期
- 研究日志工作区：按公告记录观点与风险，支持复核日期、逾期提示、原文回链和本地持久化
- 每日复盘摘要：自动统计重点事件、待跟进公告和到期复核任务
- 今日行动清单：按高影响公告和到期复核自动生成“先核验 / 待复核”行动，不直接给买卖指令
- 内置四个官方披露样例，覆盖财报、员工激励、股权变动和治理事件

## 数据说明

页面中的默认演示行情、指数卡片和 AI 研判是离线样例，不构成投资建议，也不会执行交易。切换到巨潮资讯 provider 后，公告和股票目录来自公开来源；当前 provider 不提供实时行情，因此行情字段会显示“—”，不会用样例价格冒充实时数据。

公告事件样例用于离线演示标准化结构；公开 provider 会保存抓取时间、来源和原文链接以便复核。生产环境还应接入经授权的实时行情源，并由服务端处理限流、缓存和审计。
研究日志数据仅保存在当前浏览器 localStorage；它用于形成可复核的研究轨迹，不会连接券商账户或执行交易。

## 接入公开 HTTP API

默认 provider 是演示数据。若要接入公开接口，可在 `index.html` 引入 `app.js` 之前设置配置对象：

```html
<script>
  window.TOUYANTAI_CONFIG = {
    quoteEndpoint: 'https://example.com/quotes',
    newsEndpoint: 'https://example.com/news',
    headers: {}
  };
</script>
```

切换“巨潮资讯（公开公告）”会直接请求巨潮公开股票目录与公告查询接口；浏览器若因跨域或上游限流无法访问，页面会显示数据源不可用并保留最近一次成功数据。该 provider 只提供公告与股票目录，不会填充虚构行情。

行情接口需要返回数组，或返回 `{ "stocks": [...] }` / `{ "data": [...] }`。每个标的至少提供 `code`、`name`、`price` 和 `changePercent`（也兼容 `last`、`change`、`symbol`）。页面中的“HTTP API（配置）”选项会显示加载、失败和更新时间；没有 endpoint、跨域被拒绝或字段不完整时，会保留上次数据并明确提示，不会伪装成实时行情。当前仓库未写入任何密钥。
